What the fix recovered

One claim was never wrong — it was measured in a unit that billed one arm for work the other also did. One was never testable. Here is what changed, and what a re-run would buy.

29 Aug 2026 from feat-result-01 @ 58e3302 10 files changed, 2 added no commit made

Nothing was re-run. Every number below comes from the 35,755 rounds already in data/episodes.jsonl, re-frozen and re-analysed through the project's own scripts after two changes: counting the guard's own sandbox executions, and separating the draw budget from the attempt budget.

The short version. Theorem 4.3(a) is not rejected — it holds at a rate ratio of 1.00 once both arms are charged for the same work. Corollary 4.4 was never testable, and now is. The headline saving is real but four-fifths smaller than reported, and it has a mechanism it did not have before: it concentrates on hard tasks and vanishes on easy ones.

Thm 4.3(a) — typed costs the same as untyped
rejected →held
Under oracle calls: RR 0.621 [0.566, 0.684], p = 1e−11. Under program executions: RR 0.983 [0.944, 1.020], A12 = 0.500, p = 0.66. Same episodes, same pairing. The typed arm pays more oracle calls and exactly enough fewer guard evaluations to cancel.
Cor. 4.4 — budgeted success
no effect →testable
It was not a null result. With a guarded round charged to the attempt budget the guard is provably outcome-neutral: it blocks only candidates a stored counterexample already refutes, so under common random numbers the round of the first accepted patch cannot move. untyped reproduced no_memory to the last decimal at all seven budgets. --free-guarded-rounds is what makes the corollary able to come out either way.
Memory reduces the cost of repair
2.50× →1.23×, with a gradient
1.234× [1.120, 1.364] overall — but 1.526× [1.266, 1.779] on hard and 1.024× [0.982, 1.081] on easy. A flat 2.5× had no mechanism; a saving that appears exactly where the search is hard does.
Prop. 4.5 — guard cost Θ(m) vs O(1)
supported →priced
Still true, but it is not an indexing win — it is a smaller search. On 3,170 rounds where both arms drew the byte-identical patch, 949 (29.9%) were blocked by the flat scan and missed by the type index. That cross-bucket miss rate is the price of O(1), and the paper never quoted it.
Def. 3.1 — typing coherence c
flat sweep →dropped, replaced
Not saved. The E5 sweep is underpowered (n = 90/cell, c = 1.0 scoring worse than 0.9, the random null landing mid-range) and it measures degradation under a hypothetical c, never the real one. It is dropped in favour of measuring the real c.
Guard soundness
probabilistic
The falsifier passes on all 530 cells, but 3 of 3,170 rounds show the typed guard blocking where the flat scan did not — impossible by set inclusion. _still_refutes returns True on timeout, and the timeout is wall-clock under six parallel shards. 0.09%, but it means the artifact does not reproduce bit-for-bit.
The saved claim

Why the unit was wrong. src/memory.py:_still_refutes calls run_program. A guard check is a sandbox execution, exactly like an oracle example. Counting oracle calls while ignoring guard evaluations charges one arm for work the other also performs — and the flat scan runs 1.04 guard evaluations per round against the type index’s 0.60.

The same correction deflates the headline. Model calls to first success are identical across every arm — 4.96 for no memory, 4.96 for untyped — because the loop needs the same number of rounds either way. Memory only relabels which of them are charged to the oracle.

Not run again

E1, E2, E3, E4 and E8 are complete and in the merged log. The notebook now marks them done so a re-run is a deliberate act rather than an accident.

The whole E5-c* sweep and E5-random are dropped — 18 cells × 5 seeds of model calls that measured the wrong thing underpoweredly. The data stays frozen so the artifact is whole; it is no longer a headline.

Still open

What the fix did not touch

  • Statistics. The design is paired by common random numbers and the pairing is thrown away — it wants Wilcoxon signed-rank, not Mann–Whitney. Every “no difference” sentence is an equivalence claim and needs a TOST with a declared margin.
  • Repetition count. n = 90 per E5 cell will not survive review, and the current LLM-study guidelines require the count to be justified rather than asserted.
  • Contamination. ConDefects spans Oct 2021–Sep 2023 by the paper and through Jun 2024 by the repo — state which snapshot was used. Any 2024+ open-weight model’s cutoff encloses that window. The cheap probe: prompt the model with the AtCoder statement alone and see whether it emits the reference solution.
  • Sandbox nondeterminism. A wall-clock timeout counted as a refutation makes the guard a function of machine load. A deterministic step budget would fix it.
  • Overfitting at 0.476 is reportable data, not a defect — but it needs the oracle-strength delta stated: how much does the held-out set add over the visible pool.
